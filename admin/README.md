# 모터·감속기 DB 관리 페이지 (motor_gearbox_admin.html)

Supabase(PostgreSQL)에 저장된 **모터, 유성감속기, 할로우 감속기, 어댑터플랜지 사양**을 조회·추가·수정·삭제하는 단일 HTML 페이지입니다. 여기서 고친 데이터는 감속기 선정툴(`gearbox_selector.html`)에 바로 반영됩니다.

- 파일 하나로 동작합니다. 설치나 빌드가 필요 없습니다.
- 조회는 누구나 할 수 있고, 추가·수정·삭제는 **로그인한 사용자만** 할 수 있습니다.

---

## 1. 시작하기

1. `motor_gearbox_admin.html`을 Chrome·Edge 등 브라우저로 엽니다.
2. **Supabase 연결** 화면에 두 값을 넣고 **연결**을 누릅니다.
   - **Project URL**: `https://xxxx.supabase.co`
   - **anon(public) key**
   - Supabase 대시보드 → 프로젝트 → **Connect** 버튼 (또는 Project Settings → API Keys)에서 복사합니다.
   - 값은 이 컴퓨터 브라우저에만 저장됩니다. 바꾸려면 상단의 **연결 설정**을 누릅니다.
3. **로그인** 화면에서 이메일·비밀번호로 로그인합니다. 조회만 하려면 **로그인 없이 조회만**을 누릅니다.

### 로그인 계정 만들기 (최초 1회)

Supabase 대시보드에서 계정을 만듭니다.
1. **Authentication → Users → Add user → Create new user**
2. 이메일·비밀번호를 넣습니다.
3. **Auto Confirm User**를 체크합니다.

### 권한 설정 (최초 1회, 테이블을 새로 만들 때마다)

SQL Editor에서 `supabase_policies.sql`을 실행합니다.
- 조회: `anon`, `authenticated` 모두 가능
- 추가·수정·삭제: `authenticated`(로그인 사용자)만 가능
- 조회용 뷰는 호출한 사람의 권한으로 동작하도록 설정합니다.

> 인터넷 연결이 필요합니다. 페이지가 `@supabase/supabase-js`와 Pretendard 글꼴을 CDN에서 받아 옵니다.

## 2. 화면 구성

상단 탭 4개. 탭 이름 옆 숫자는 행 수입니다.

| 탭 | 테이블 | 한 행 = |
|---|---|---|
| 모터 | `motor` (+ `manufacturer`, `motor_series`, `motor_basic_type`) | 모터 1개 |
| 유성감속기 | `planetary_gearbox` | 시리즈·사이즈·감속비 1개 |
| 할로우 감속기 | `hollow_gearbox` | 시리즈·사이즈·구분·감속비 1개 |
| 어댑터플랜지 사양 | `model` + `interface` + `model_interface` | 시리즈·사이즈 1개와 ST/SV 슬롯 |

공통 기능:
- **필터·검색**: 탭마다 필터 드롭다운(제조사·시리즈 / 시리즈·사이즈)과 검색창이 있습니다.
- **정렬**: 컬럼 머리글을 누르면 정렬됩니다.
- **단위 표시**: 컬럼 이름 아래에 단위가 표시됩니다.
- **새로고침**: DB에서 다시 읽어 옵니다.
- **현재 목록 CSV로 받기**: 필터가 적용된 목록을 CSV로 내려받습니다.

## 3. 추가·수정·삭제

행을 누르면 오른쪽에 편집 패널이 열립니다.

| 버튼 | 동작 |
|---|---|
| 저장 | 바뀐 내용을 저장 |
| 복사해서 추가 | 지금 행을 복사해 새 행으로 (감속비만 바꿔 추가할 때 편리) |
| 삭제 | 한 번 누르면 "한 번 더 누르면 삭제"로 바뀌고, 4초 안에 다시 누르면 삭제 |
| 새로 추가 (목록 위) | 빈 양식으로 새 행. 지금 걸려 있는 필터 값(예: 시리즈)이 미리 채워짐 |

필수 항목이 비었거나 형식이 틀리면 저장되지 않고 해당 칸에 이유가 표시됩니다.

### 3-1. 모터 탭

| 묶음 | 항목 |
|---|---|
| 분류 | 제조사, 시리즈, 기본형, 모델 코드(필수), 모터 종류(기본 `servo motor`), 전압(기본 `230V AC`) |
| 성능 | 정격토크, 최대토크, 정격속도, 최대속도, 관성모멘트, 정격출력 |
| 플랜지 | 축경, 축 길이, 파일롯경, PCD, 체결나사, 체결방식(기본 `B5`) |

- 제조사·시리즈·기본형이 DB에 없는 이름이면 **자동으로 새로 만들어** 연결합니다.
- 체결나사는 `M4`, `M2.5` 형식입니다. `m2_5`, `M2,5`, `M 2.5`처럼 넣어도 `M2.5`로 고쳐 저장합니다.
- 스테핑 모터는 모터 종류에 `step`·`스테핑`·`스텝` 중 하나가 들어가야 선정툴에서 ST 슬롯으로 판정됩니다.

### 3-2. 유성감속기 탭

| 항목 | 규칙 |
|---|---|
| 시리즈 | 필수. 대문자 (예: `GPB`) |
| 사이즈 | 필수. **세 자리** (예: `042`). `42`로 넣으면 `042`로 맞춥니다 |
| 감속비 코드 | 필수. `10K` 형식 |
| 단수 | `L1` / `L2` (도면 키에 사용) |
| 성능·하중 | 정격토크, 관성, 정격·최대 입력속도, 비틀림강성, 효율(`0.97`처럼 소수), 레이디얼·액시얼 하중, 무게, 소음, 백래시 |

### 3-3. 할로우 감속기 탭

| 항목 | 규칙 |
|---|---|
| 시리즈, 사이즈 | 필수 (예: `GSN`, `85`) |
| 구분(variant) | 없음 / M / Z / ZL / ZR / F / E / C |
| 플랜지 사이즈 | 사이즈+구분으로 자동 입력 (예: `85Z`). 예외: GSN 85 18K는 `85-18K` |
| 감속비 코드 | `10K` 또는 `104.43K` 형식 |
| 성능·하중 | 정격토크 … 틸팅모멘트, 백래시 |

플랜지 사이즈는 어댑터플랜지 사양 탭의 사이즈와 같아야 선정툴에서 연결됩니다.

### 3-4. 어댑터플랜지 사양 탭

- 한 행 = 시리즈·사이즈 1개(`model`)이고, 슬롯이 **ST1~ST4**(스테핑)와 **SV1~SV9**(서보)까지 있습니다.
- 슬롯 값 형식은 `축경-파일롯경-PCD-체결나사`입니다. 예: `14-50-70-M5`, `6.35-22-31-M2.5`
- DB에 없는 사양 코드를 넣으면 `interface` 테이블에 자동으로 추가합니다.
- 저장하면 그 사이즈의 슬롯 연결(`model_interface`)을 지우고 화면 내용대로 다시 씁니다.
- 사이즈는 감속기 테이블과 같은 표기여야 합니다.
  - 유성: 세 자리 (`060`)
  - 할로우: 플랜지 사이즈 (`85Z`, `85-18K`)

> **주의:** 어댑터플랜지 탭에서 행(시리즈·사이즈)을 삭제하면 그 사이즈의 슬롯 연결도 모두 함께 지워집니다.

## 4. CSV로 한꺼번에 추가·수정

**새로 추가**를 누르고 패널 위쪽에서 **CSV 파일 (여러 건)**을 고르면 여러 행을 한 번에 넣을 수 있습니다.

1. **빈 양식 받기**로 그 탭의 CSV 양식을 받습니다. **현재 목록 CSV로 받기**로 받은 파일을 고쳐 써도 됩니다.
2. 엑셀에서 작성해 CSV로 저장합니다. UTF-8과 엑셀 기본 "CSV (쉼표로 분리)"(EUC-KR) 모두 읽습니다.
3. 파일을 끌어다 놓거나 **파일 선택**으로 올리면 미리보기가 나옵니다. 각 행이 **추가 / 이미 있음 / 오류**로 표시되고, 오류 행이 맨 위에 나옵니다.
4. 이미 있는 행 처리를 고르고 **N건 반영**을 누릅니다.
   - **건너뛰기**: 이미 있는 행은 그대로 둡니다.
   - **덮어쓰기(수정)**: CSV에 있는 컬럼만 바꿉니다. CSV에 없는 컬럼의 기존 값은 그대로 둡니다.

| 탭 | "이미 있음" 판단 기준 |
|---|---|
| 모터 | 제조사 + 모델 코드 |
| 유성감속기 | 시리즈 + 사이즈 + 감속비 코드 |
| 할로우 감속기 | 시리즈 + 사이즈 + 구분 + 감속비 코드 |
| 어댑터플랜지 | 시리즈 + 사이즈 |

- 머리글은 DB 컬럼 이름(`rated_torque`)이나 화면 라벨(`정격토크`) 어느 쪽도 됩니다.
- 새 행은 200건씩 묶어 넣고, 묶음이 실패하면 한 건씩 다시 넣어 실패한 행만 표시합니다.

## 5. 알아 둘 점 (현재 화면에 없는 컬럼)

나중에 추가한 아래 컬럼은 아직 편집 화면과 CSV 가져오기에 없습니다. Supabase **Table Editor**에서 고치거나, 다시 넣기 SQL(`planetary_gearbox_reload.sql`, `hollow_gearbox_reload.sql`)을 사용하세요.

| 테이블 | 컬럼 |
|---|---|
| `planetary_gearbox` | `P1`, `P2`(백래시 등급별 값), `backlash_unit` |
| `hollow_gearbox` | `gearing`, `support_bearing`, `repeatibility`·`repeatibility_unit`, `positioning`·`positioning_unit` |
| `series` | `description` (시리즈 설명) |

화면의 **백래시** 칸은 예전 `backlash` 컬럼입니다. 선정툴은 유성감속기의 `P1`/`P2`, 할로우의 반복정밀도·포지셔닝을 사용합니다.

## 6. 자주 묻는 문제

| 증상 | 확인할 것 |
|---|---|
| 연결 후 목록이 비어 있음 / 오류 | Project URL·anon key, `supabase_policies.sql` 실행 여부 |
| 저장·삭제 버튼이 안 보이거나 막힘 | 로그인했는지 (상단 상태 표시) |
| "permission denied" / "row-level security" 오류 | `supabase_policies.sql` 다시 실행 (테이블을 새로 만들었으면 필수) |
| 로그인 실패 | Authentication → Users에 계정이 있고 확인(Confirmed) 상태인지 |
| CSV 한글이 깨짐 | 엑셀에서 "CSV UTF-8" 또는 "CSV (쉼표로 분리)"로 저장했는지 |
| 선정툴에서 새 감속기가 어댑터 없음으로 나옴 | 어댑터플랜지 탭에 같은 시리즈·사이즈(유성 세 자리, 할로우 플랜지 사이즈) 행과 슬롯이 있는지 |
| 체결나사 입력이 거부됨 | `M` + 숫자 형식인지 (`M4`, `M2.5`) |
