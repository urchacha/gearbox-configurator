# 감속기 선정툴 (gearbox_selector.html)

모터를 고르면 그 모터에 장착할 수 있는 **유성감속기·할로우로터리**를 Supabase DB에서 찾아 토크를 비교하고, 어댑터플랜지·부싱 조합과 도면까지 안내하는 단일 HTML 페이지입니다.

- 파일 하나(`gearbox_selector.html`)로 동작합니다. 설치나 빌드가 필요 없습니다.
- 데이터는 Supabase(PostgreSQL)에서 읽기만 합니다. 데이터 추가·수정은 관리 페이지(`motor_gearbox_admin.html`)에서 합니다.

---

## 1. 시작하기

1. `gearbox_selector.html`을 더블클릭해 Chrome·Edge 등 브라우저로 엽니다.
2. 처음 열면 **Supabase 연결** 화면이 나옵니다. 두 값을 넣고 저장합니다.
   - **Project URL**: `https://xxxx.supabase.co`
   - **anon(public) key**
   - Supabase 대시보드 → 프로젝트 → **Connect** 버튼 (또는 Project Settings → API Keys)에서 복사합니다.
3. 값은 이 컴퓨터 브라우저에만 저장됩니다. 바꾸려면 상단의 **연결 설정** 버튼을 누릅니다.

> 인터넷 연결이 필요합니다. 페이지가 아래 두 파일을 CDN에서 받아 옵니다.
> - `@supabase/supabase-js@2.45.4` (jsDelivr)
> - Pretendard 글꼴

---

## 2. 사용 순서 (5단계)

| 단계 | 화면 | 하는 일 |
|---|---|---|
| 1 | 모터 선택 | 브랜드·타입으로 좁히고 모델을 검색해 **모터 선택**. **선택 해제**를 누르면 모델 칸이 비워져 다시 고를 수 있습니다. |
| 2 | 모터 확인 | 모터 사양(축경·파일롯경·PCD·체결나사·토크·속도 등)과 장착 방식(B5 관통 홀 / B14 탭가공 홀)을 확인합니다. |
| 3 | 감속기 조건 | 감속기 종류, 선정 범위, 사용 조건을 정합니다 (아래 3-1). |
| 4 | 감속기 선택 | 조건에 맞는 조합을 표로 비교하고 한 행을 고릅니다. |
| 5 | 최종 확인 | 모터 + 감속기·어댑터플랜지 (+ 부싱) 조합, 사양 비교, 도면 다운로드, 요약 복사, 인쇄/PDF. |

### 3-1. 3단계 감속기 조건

**감속기 종류**: 유성감속기 / 할로우로터리 / 전체

- 종류 박스를 **클릭하면** 사진 팝업이 열립니다. 이미 선택된 박스를 다시 눌러도 열립니다.
- 팝업에서 사진(100×100)을 누르면 그 시리즈가 바로 **감속기 지정**으로 선택됩니다.
- 사진 위에는 `series` 테이블의 설명(description)이, 아래에는 파일명이 표시됩니다.
- 사진이 많으면 팝업 안에서 스크롤됩니다.

**선정 범위**

| 모드 | 설명 |
|---|---|
| 감속기 지정 | 시리즈 → 사이즈 → 감속비를 직접 고릅니다 (아래 정밀도 항목 포함). |
| 감속비만 지정 | 감속비만 여러 개 골라 전 시리즈에서 비교합니다. |
| 전체 보기 | 모든 감속기를 비교합니다. |

감속기 지정의 정밀도 항목은 종류에 따라 다릅니다.
- 유성감속기: 백래시 등급 **P2(표준) / P1(정밀)**. 선택한 범위의 값 범위가 함께 표시됩니다.
- 할로우로터리: **반복정밀도**, **포지셔닝** 필터.

시리즈·사이즈 목록에는 모터 축에 맞는 것만 나옵니다. 사이즈 옆에 `직결 · 입력홀 14`, `부싱 G19S14 · 입력홀 19`처럼 장착 방식이 표시됩니다. 입력 홀·어댑터 정보가 아직 없는 시리즈는 `(입력홀·어댑터 미등록)`으로 표시됩니다 (4-4 참고).

**사용 조건**

| 항목 | 설명 |
|---|---|
| 사용계수(안전율) | 기본 1.5 |
| 부하 토크 | 선택. 입력하면 출력 토크가 이보다 작은 조합은 부적합 처리됩니다. |
| 효율 반영 | 감속기 효율(η)을 토크 계산에 넣을지 정합니다. |

### 4단계 표

- 정렬: 여유율 낮은 순 / 사이즈 순 / 감속비 순
- 필터: **부적합 숨기기**, **어댑터 있는 것만**
- 어댑터는 이 단계에서 표시만 하고, **5단계로 넘어갈 때** 확인합니다. 맞는 어댑터가 없으면 넘어가지 않고 이유를 알려 줍니다.

## 3. Supabase 준비물

### 3-1. 테이블 (읽기 전용)

| 테이블 | 필수 | 용도 |
|---|---|---|
| `manufacturer`, `motor_series`, `motor_basic_type`, `motor` | ✔ | 모터 목록·사양 |
| `planetary_gearbox` | ✔ | 유성감속기 (감속비·정격토크·효율·속도·P1/P2 백래시 등) |
| `hollow_gearbox` | ✔ | 할로우로터리 (flange_size, 반복정밀도·포지셔닝 등) |
| `model`, `interface`, `model_interface` | ✔ | 시리즈·사이즈별 어댑터플랜지(ST/SV 슬롯) 사양 |
| `series` | 선택 | 시리즈 설명 → 사진 팝업에 표시 |
| `basic_dimension` 또는 `input_hole` | 선택 | 시리즈·사이즈별 감속기 입력 홀 지름 |
| `bushing` | 선택 | 부싱 (모터 축경 → 감속기 입력경) |

- 선택 테이블이 없거나 읽지 못해도 페이지는 동작하고, 해당 기능만 빠집니다.
- 입력 홀 테이블은 `basic_dimension`을 먼저 찾고, 없으면 `input_hole`을 씁니다. 컬럼 이름은 자동으로 인식합니다.
  - 시리즈: `series_code` 또는 `series`
  - 사이즈: `size`
  - 입력 홀: `basic_hole`, `input_hole`, `input_hole_dia`, `hole`, `input_g`, `gearbox_input_dia`, `input_dia` 중 하나
- `bushing`에 `series_code`·`size` 컬럼이 있으면, 그 시리즈·사이즈 전용 부싱을 먼저 고릅니다.
- 권한: 모든 테이블에 `anon` 읽기(SELECT)가 있어야 합니다. `supabase_policies.sql`을 실행하면 설정됩니다.

### 3-2. 스토리지 버킷

| 버킷 | 용도 | 파일 규칙 |
|---|---|---|
| `catalogue` | 카탈로그 다운로드 | `planetary.pdf`, `hollow.pdf` |
| `photo` | 3단계 사진 팝업 | 하위 폴더 이름으로 종류 구분: 유성 `planetary`·`유성`·`GP…`, 할로우 `hollow`·`할로우`·`rotary`·`GS…`. 하위 폴더까지 모두 찾습니다. 이미지: jpg, png, webp, gif, bmp |
| `download` | 5단계 도면 다운로드 | 파일명 = 도면 키 + `.pdf` / `.step` / `.stp`. 하위 폴더까지 모두 찾습니다. |

- 비공개 버킷이면 서명 URL로, 공개 버킷이면 공개 URL로 읽습니다. 비공개 버킷은 `anon`에 읽기(select) 정책이 필요합니다.
- 사진 파일명(또는 사진이 든 폴더 이름)이 **시리즈 코드로 시작**해야 사진 클릭으로 시리즈가 선택되고 설명이 붙습니다.
  - 예: `GPB.jpg`, `GPB_외형.png`, `GSN85Z.png`, `photo/planetary/GPB/1.jpg`
  - 긴 코드를 먼저 비교합니다 (`GPBR.png` → GPBR).

## 4. 선정 로직

### 4-1. 토크

```
출력 토크      = 모터 정격토크 × 감속비 × 효율(η, 반영 시)
필요 정격토크  = 출력 토크 × 사용계수
여유율         = 감속기 정격토크 ÷ 필요 정격토크   (100% 이상 = 적합)
```

- 감속비는 감속비 코드에서 읽습니다. `10K` → 10, `104.43K` → 104.43
- 속도는 판정에 쓰지 않습니다. 모터 정격·최대 속도가 감속기의 정격·최대 입력속도를 넘으면 **주의** 메시지만 표시합니다.

### 4-2. 축 장착 (3단계 사이즈 목록)

1. 입력 홀 표가 있으면:
   - 입력 홀 = 모터 축경 → **직결**
   - 입력 홀 > 모터 축경이고 맞는 부싱이 있으면 → **부싱** (예: `G19S14` = 입력경 19, 모터 축 14)
2. 위가 안 되면, 모터 축경과 같은 축경의 어댑터가 있을 때 → **어댑터 직결** (예: 스테핑 6.35축)
3. 입력 홀 표가 없으면 어댑터(ST/SV)의 축경으로 같은 방식으로 판단합니다.

### 4-3. 어댑터플랜지 (4 → 5단계)

- 슬롯 종류: 모터 종류에 `step`·`스테핑`·`스텝`이 있으면 **ST**, 그 외는 **SV**
- 파일롯경, PCD, 체결나사가 모두 같아야 합니다.
  - 스테핑 모터는 PCD가 사각 볼트 간격으로 적힌 경우가 많습니다. 그래서 `PCD × √2`도 같은 것으로 봅니다 (예: 31 → 43.8).
- 축경이 같으면 직결, 다르면 부싱으로 맞춥니다. 직결을 먼저 고릅니다.

### 4-4. 입력홀·어댑터 미등록 시리즈

입력 홀과 어댑터 정보가 하나도 없는 시리즈·사이즈(예: 새로 넣은 GBX)도 목록에 나오고 토크 비교는 됩니다. 다만 축이 맞는지 알 수 없어 **5단계로는 넘어가지 않습니다.** 관리 페이지에서 어댑터플랜지 사양을 등록하면 정상적으로 판정됩니다.

### 4-5. 표기 규칙

| 항목 | 형식 | 예 |
|---|---|---|
| 감속기 형번 | 시리즈+사이즈-감속비 | `GPB060-10K`, `GSN85Z-10K` |
| 조합 | 모터 + 형번-(어댑터 코드) [+ 부싱] | `HG-KR43 + GPB060-10K-(14-50-70-M5) + G19S14` |
| 도면 키 (유성) | 시리즈+사이즈-단수-(어댑터 코드) | `GPB090-L1-(19-70-90-M5)` |
| 도면 키 (할로우) | 시리즈+사이즈-감속비-(어댑터 코드) | `GSH100-30K-(14-50-70-M5)` |

어댑터 코드는 `축경-파일롯경-PCD-체결나사` 입니다.

## 5. 자주 묻는 문제

| 증상 | 확인할 것 |
|---|---|
| 처음 화면에서 데이터를 못 읽음 | Project URL·anon key, 테이블 읽기 권한(`supabase_policies.sql`) |
| 시리즈 목록에 원하는 시리즈가 없음 | 그 시리즈의 입력 홀·부싱·어댑터 정보가 모터 축경과 맞는지. 감속기 테이블에 행이 있는지 |
| 사진 팝업이 비어 있음 | `photo` 버킷 폴더 이름(planetary/hollow 등), 버킷 읽기 정책 |
| 사진을 눌러도 선택되지 않음 | 파일명·폴더 이름이 시리즈 코드로 시작하는지. 흐린 사진은 그 모터에 맞는 사이즈가 없는 시리즈 |
| 사진 위 설명이 비어 있음 | `series` 테이블에 그 시리즈의 description이 있는지 |
| "어댑터 없음"으로 5단계에 못 감 | `model`·`model_interface`에 그 사이즈의 ST/SV 슬롯이 있는지. 파일롯경·PCD·체결나사가 모터와 같은지 |
| 도면이 안 나옴 | `download` 버킷 파일명이 도면 키와 같은지 (`.pdf` / `.step` / `.stp`). 유성은 `stage`(단수) 값이 필요 |
| 감속비가 이상함 (예: 10443) | `hollow_gearbox.ratio`가 소수형인지 (`hollow_gearbox_reload.sql` 실행) |
